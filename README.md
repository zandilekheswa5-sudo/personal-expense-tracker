# 💰 Personal Expense Tracker

A command-line personal expense tracker built with Python.

The application allows users to record, view, calculate, and delete
expenses while storing their data in JSON and CSV files.

## 🚀 Features

- Add expenses
- Choose expense categories
- Validate expense amounts
- Prevent negative or zero amounts
- Handle invalid number input
- View all recorded expenses
- Calculate total expenses
- View spending by category
- Delete expenses
- Store data in JSON
- Export data to CSV
- Persistent expense data between sessions

## 🛠️ Technologies Used

- Python 3
- JSON
- CSV
- Python `datetime`
- File handling
- Lists and dictionaries
- Loops
- Conditional statements
- Exception handling
- Functions and data processing
